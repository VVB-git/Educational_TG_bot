## [0.1.0] - 2026-09-02

### Added

- Локальный бот на aiogram 3: `/start` → роль → тема → вопрос → ответ → назад.
- Реестр ролей в `bot/roles.py`: ассистент аккаунт-менеджера и администратор.
- SQLite (`data/bot.sqlite3`): темы и вопросы, поле `images` под будущие скриншоты.
- Сид из переписанных заметок Obsidian (`bot/content/`).
- Админка в чате: новая или существующая тема, вопрос, ответ из нескольких сообщений, подтверждение.
- `is_admin()` всегда возвращает True (тест); место под `ADMIN_IDS` уже есть.

### Content

Сид для роли `am_assistant`:

- Счета и документы: выставление счетов (два счёта РК/сегменты, смена банка).
- Отчеты: название, таблица лидов, статистика по баннерам, еженедельный отчёт по Сподвижникам.
- Аналитика: Post-view, прямые и ассоциированные Post-click, CPL, бюджет цикла, лимиты Метрики.
- Клиент «Сподвижники»: ссылки на таблицы, без реальных паролей.
- Шаблоны: запрос Жене, резюме по циклу.
- База: продукты, термины, виды лидов, заглушки по PPT и Search Lift.

### Gaps

В исходных заметках не хватало текста — в боте это сказано прямо:

- Search Lift — только два шага, регламента нет.
- «Что делать, если просят отключить PPT» — ответа не было.
- Еженедельный отчёт по Сподвижникам — только ссылка на видео.
- Нет файлов скриншотов (лиды, Post-click, CPL, презентация). В текстах пометка «здесь будет скриншот».
- Длинная «Презентация програматика» сжата до терминов, продуктов и видов лидов; личные пометки со обучения не переносились.
- Живые логины и пароли из заметок не копировались.

### Security

- Пароли из хранилища в бот не попали.
- Кнопка администратора пока без проверки пользователя.
