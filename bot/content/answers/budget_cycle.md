**Бюджет цикла производства (для брифа)**

Формула:

`= сумма_из_МП / 1,05 * 75% * 25%`

Число **205918** (или другое) берётся из медиаплана (МП) — это сумма из МП.

1. Возьмите сумму из медиаплана.
2. Разделите на 1,05.
3. Умножьте на 75%.
4. Умножьте на 25%.

Полученное число — бюджет производства на цикл для брифа.
