**Как выгрузить Post-view конверсии**

**1. Данные в админке**

1. Откройте админку.
2. Перейдите в охватные кампании.
3. Найдите нужного клиента.
4. Откройте колонку «post view отчёт».
5. Выберите период.
6. Нажмите «Обновить».
7. Скачайте файл.

**2. Работа в таблице**

1. Включите фильтр.
2. Отфильтруйте строки по целям.
3. Скопируйте нужные строки на отдельный лист.
4. По полю clientID YM удалите дубли (оставьте по одной строке на clientID).

Колонки, которые можно удалить как служебные:

`ID Кампании`, `Название кампании`, `Тип события`, `ID Баннера`, `Трекинг система`, `Домен`, `ОС`, `Браузер`, `Устройство`, `Регион`, `IP`, `Programmatic ID`.
