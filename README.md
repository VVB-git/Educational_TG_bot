# Telegram-бот для ассистентов AM

Подсказки по работе для новичков: человек выбирает роль, тему и вопрос — бот показывает пошаговый ответ. Команды знать не нужно, всё кнопками.

Сейчас две роли:

- **Ассистент аккаунт-менеджера** — читает ответы
- **Администратор** — добавляет новые вопросы и ответы прямо в чате

На этом этапе бот работает **на вашем компьютере**. Пока открыт терминал с программой — бот отвечает. Закрыли окно или выключили ПК — для всех он молчит.

## Как запустить

1. Создайте бота в Telegram: откройте [@BotFather](https://t.me/BotFather), команда `/newbot`, скопируйте токен.
2. В папке проекта скопируйте `.env.example` в файл `.env` и вставьте токен:

```
BOT_TOKEN=ваш_токен_сюда
```

3. В PowerShell, в папке проекта:

```powershell
.\.venv\Scripts\Activate.ps1
python -m bot
```

Если виртуального окружения ещё нет:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m bot
```

Команда `python` из Microsoft Store может не работать — используйте `.\.venv\Scripts\python.exe -m bot` или интерпретатор Python 3.12.

4. Найдите своего бота в Telegram и нажмите **Start**.

Остановка: в терминале `Ctrl+C`.

## Как добавить роль в коде

В [bot/roles.py](bot/roles.py) добавьте строку в список `ROLES`:

```python
Role(id="new_role", title="Название на кнопке", kind="reader"),
```

`kind="reader"` — человек читает FAQ. `kind="admin"` — меню добавления вопросов. Хендлеры копировать не нужно: кнопка на `/start` появится сама. Вопросы для новой роли можно сразу завести через администратора.

## Админ

Кнопка «Администратор» пока открыта всем (для теста). В [bot/auth.py](bot/auth.py) уже есть заглушка `is_admin()`: позже достаточно включить проверку `ADMIN_IDS` в `.env`, хендлеры не переписывать.

Админ выбирает роль → тему (или создаёт новую) → пишет вопрос → ответ (можно несколькими сообщениями) → «Готово» → «Сохранить».

## Картинки

В ответах есть пометки «здесь будет скриншот». Файлы пока не подключены. Когда появятся — кладите в `assets/images/` и допишем отправку в код.
